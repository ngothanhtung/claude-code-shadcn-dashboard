The `(private)` route group is a Next.js App Router segment that applies a single client-side `layout.tsx` to every child page. The layout composes `SidebarProvider`, `AppSidebar`, `SiteHeader`, `SiteFooter`, and `ThemeCustomizer` around `{children}`, with left/right sidebar positioning controlled by `useSidebarConfig`. All feature sub-pages — settings (account/appearance/connections/notifications/user), productivity features (tasks/calendar/documents), communication (chat), and dashboards (dashboard/dashboard-2/admin/users/customers) — render inside this shared shell without re-implementing chrome, ensuring consistent navigation, theming, and responsive behavior across the entire authenticated area.
