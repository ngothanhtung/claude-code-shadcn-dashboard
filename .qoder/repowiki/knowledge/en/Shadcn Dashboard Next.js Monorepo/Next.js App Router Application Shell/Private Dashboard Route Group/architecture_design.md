The `(private)` route group is a Next.js App Router segment whose `layout.tsx` renders a `SidebarProvider` shell around `{children}`. The layout reads `useSidebarConfig()` to decide left/right sidebar placement, then composes `AppSidebar`, `SiteHeader`, `SiteFooter`, and an overlay `ThemeCustomizer`. Every feature sub-page — settings (account/appearance/connections/notifications/user), productivity features (tasks/calendar/documents), communication (chat), and dashboards (dashboard/dashboard-2/admin/users/customers) — mounts inside this shared shell via Next.js route-group composition, so no child re-implements navigation or theming.
