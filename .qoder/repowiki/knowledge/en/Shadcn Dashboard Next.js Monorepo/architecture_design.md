A single Next.js 16 app (App Router) owns the runtime; child packages are not separate npm packages but sibling source trees under `src/` consumed via the `@/*` path alias declared in `tsconfig.json`. The shell (`app_shell`) registers route groups for public pages, authenticated dashboard routes, and server-side API endpoints. Feature modules (`business_features`, `dashboard_features`) import shared UI primitives from `ui_components` and runtime services (auth, Firebase client/admin SDKs, theme provider, hooks) from `cross_cutting`; `shared_features` provides the dashboard chrome and auth provider that wrap those features. `components.json` centralizes shadcn/ui configuration (New York style, CSS variables, lucide icons) so every child generates components against the same design tokens. `firestore.rules` is the single security boundary enforced at the database layer across all feature modules.
